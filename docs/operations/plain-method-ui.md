# Plain methodology UI

The standalone methodology route deliberately uses a basic late-1990s HTML-document presentation.

It keeps the shared application header and menu, then renders the method as one linear reference document using headings, paragraphs, numbered or bulleted lists, horizontal rules and ordinary underlined links.

It must not be converted into cards, dashboards, four-column criterion grids, split hero panels or repeated boxed sections. This rule is presentational only and does not alter the review protocol.
