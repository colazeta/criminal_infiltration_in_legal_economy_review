# CILE Kora control-plane pilot

This bundle is the first Kora pilot for `criminal_infiltration_in_legal_economy_review`.

It deliberately does **not** create another scheduler and does **not** write to the private enrichment store. It mirrors the current two-lane completion-first router and makes the F0–F7 frontier observable in Kora run evidence.

## What v0.1 proves

- Kora can receive an activation as a message rather than own :10/:40 cadence.
- The F0–F7 frontier can be reconstructed deterministically from persisted-state predicates.
- The lane router can be replayed and audited without changing the live CILE pipeline.
- `Completed` remains F5 assessment-complete; `Validated` remains separate.
- Lane B alone may route to shared engineering.
- WIP and state inconsistencies fail closed.

## Not yet included

- no Parallel Search call;
- no private enrichment-store read/write;
- no GitHub mutation;
- no agent-authored scientific proposal;
- no human validation task;
- no release or deployment.

These are phase-2 additions after Kora environment/extension discovery and source validation.
